# flask-aws-file-manager
Flask file management application deployed on AWS using EC2, S3, RDS PostgreSQL and CloudWatch.

Flask AWS File Manager
Web application developed with Python and Flask, deployed on Amazon EC2.

Architecture
EC2 → Flask

├── S3

├── RDS PostgreSQL

└── CloudWatch

Features
Upload files
Download files
Delete files
View metadata
Storage in S3
Persistence in RDS
Monitoring via CloudWatch
